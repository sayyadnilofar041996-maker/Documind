DocuMind Project Assets Manifest (Clean Workspace Files)
=========================================================

This file lists the verified necessary files in the project root directory for the external viva presentation and runtime operation.

1. Reports & Slides (DOCX & PPTX)
--------------------------------
* Documind_MCA_Project_Documentation_Final_v2.docx   - The final written report of the DocuMind platform.
* DocuMind_Presentation.pptx                         - The slide deck for the external viva presentation.

2. Configuration & Dependency Files (TXT, MD & INI)
---------------------------------------------------
* requirements.txt          - Core Python backend framework and model dependencies.
* pip_freeze.txt            - Installed libraries list for virtual environment validation.
* alembic.ini               - Database migration tool settings file.
* README.md                 - Basic repository overview, setup, and run instructions.
* documind_documentation.md  - Deep dive documentation covering system design.
* .env                      - Local environment variables and API keys configuration.
* .dockerignore / .gitignore- Docker and Git exclude rule manifests.
* docker-compose.yml        - Orchestration layout file for PostgreSQL, Redis, Celery, and API.
* Dockerfile / Dockerfile.worker - Docker image build manifests for the backend & workers.

3. Running & Compilation Core Scripts
-------------------------------------
* run.py                       - Master controller to spin up services and load the app.
* gen_documind_mca_report_v7.py - The latest active script used to compile the documentation report.
* generate_pptx.py             - The slide deck compiler script.
